# disc-vault
DiscVault is an offline catalog for CD/DVD archives. It indexes every disc's folders and files (311 discs, 42K+ folders, 345K+ files) into a searchable database, so you can instantly find which physical disc holds a file — by name, type, or path — without inserting or searching discs manually.

Sign in with Google and each account gets its own private catalog. See [WEB_APP_ARCHITECTURE.md](WEB_APP_ARCHITECTURE.md).
